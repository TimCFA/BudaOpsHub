fake names, invented ratings, every product cost 0. Shapes follow
`rules/API.md`; the story follows `docs/SPEC.md` (Saturday 2026-10-03, 10:52).

## Conventions

- Times in data are minutes since midnight, except roster `start`/`end`
  (`'H:MM'` 24 h, per the SPEC) and PEA `at` (`'YYYY-MM-DDTHH:MM'`).
- **Assignment keys in `scenario.js` and `history.js` are raw slot names**, the
  same strings as in `positions.js`. The store maps a name to a slot id with
  `rules/positions.js slotFromName(name, side).id`; the rules id scheme is not
  duplicated here.
- Position names on the board stay as the floor says them in both languages.
- Waste entries carry `date` and `at` (minutes) separately so `todayCount`
  and `tape` need no date parsing.
